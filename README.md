# Шпион Online — сервер для игры с друзьями

Отдельное приложение (не связано с локальной версией в папке `sp/`). Один человек запускает сервер,
остальные заходят по ссылке с любого устройства — у каждого своя роль, таймер и раскрытие шпиона синхронны у всех.

## Что нужно один раз

1. Установите Node.js (LTS): https://nodejs.org — просто скачать и поставить, как обычную программу.
2. Откройте терминал в папке `online-server` и выполните:

```bash
npm install
```

## Запуск

```bash
npm start
```

Сервер поднимется на `http://localhost:3000`. Если открыть эту ссылку в браузере — увидите игру.

## Как дать доступ друзьям через интернет

Сам по себе `localhost:3000` виден только на вашем компьютере. Чтобы друзья зашли **из любой точки**, нужен один из двух вариантов:

### Вариант А — быстрый туннель (для разовой игры сегодня)

Не требует регистрации, работает пока запущен и ваш компьютер включён:

```bash
npx localtunnel --port 3000
```

Команда выдаст ссылку вида `https://random-name.loca.lt` — её и скидываете друзьям. Закроется, как только остановите команду или выключите компьютер.

### Вариант Б — бесплатный хостинг (надёжнее, работает всегда)

Например, [Render.com](https://render.com) (есть бесплатный тариф):

1. Зарегистрируйтесь на Render, подключите свой GitHub-репозиторий с этой папкой (или загрузите код напрямую).
2. Создайте **Web Service**, укажите:
   - Build Command: `npm install`
   - Start Command: `npm start`
3. После деплоя Render даст постоянную ссылку вида `https://ваша-игра.onrender.com` — она будет работать всегда, не завися от вашего компьютера.

Это чуть дольше настроить в первый раз, зато не нужно держать свой компьютер включённым во время игры, и ссылка не меняется каждый раз.

## Как играть

1. Хост открывает ссылку → «Создать комнату» → вводит имя.
2. Хост говорит остальным 5-значный код комнаты (или скидывает ссылку + код).
3. Остальные открывают ту же ссылку → вводят код и имя → «Присоединиться».
4. Хост выбирает категорию и таймер в лобби, жмёт «Начать игру» (нужно минимум 3 игрока).
5. У каждого на своём экране появляется своя роль — нажимает «Готов(а)», когда посмотрел(а).
6. Как только все нажали (или хост форсирует старт) — начинается синхронный таймер обсуждения.
7. Хост завершает обсуждение → сначала раскрывается шпион, затем отдельной кнопкой — локация/персонаж.
8. Хост жмёт «Новая игра» — возвращает всех в лобби для следующего раунда с теми же настройками.

## Известные ограничения (осознанный компромисс ради простоты)

- Данные о комнатах хранятся в памяти сервера — при перезапуске сервера (и на бесплатном тарифе Render — при засыпании сервера от бездействия) все активные комнаты пропадают.
- Локации/персонажи фиксированные (копия из `sp/locations.js` и `sp/characters.js` на момент создания). Правки через «Управление контентом» в локальной версии сюда не попадают — это раздельные системы.
- Если во время раунда отключится хост, следующий игрок в списке становится хостом, но кнопки управления на его экране появятся только после переподключения любого игрока или смены фазы.
- Переподключение при обрыве связи работает (5 минут на возврат — игрок возвращается в ту же роль и фазу), но требует той же вкладки браузера (используется `sessionStorage`). Если вкладка закрыта или это другое устройство — нужно зайти заново по коду комнаты (комната сохранится, если остались другие игроки).
